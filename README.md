# Shop-pur — E-commerce Website

A responsive multi-page e-commerce website frontend for browsing electronics and home-appliance categories.

## Live Demo

[Open Shop-pur](https://kashish-tech2077.github.io/Shop-pur-E-commerce/)

## Repository

[GitHub Repository](https://github.com/Kashish-tech2077/Shop-pur-E-commerce)

## Features

- Responsive e-commerce layout
- Product categories and dedicated product pages
- PCs & laptops, televisions, smartphones, tablets, smart watches, and home appliances
- Hero, brand, and testimonial sliders
- Responsive navigation menu
- Sticky navigation and scroll-to-top interaction
- Animated counters
- Contact form using Formspree

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Swiper.js
- Keen Slider
- Formspree
- Font Awesome
- Ionicons

## Architecture & Functionality

The project is a static, multi-page frontend. HTML provides the structure, CSS handles styling and responsive layouts, and JavaScript provides navigation behavior, sliders, animated counters, sticky navigation, and other interactions.

External libraries are loaded through CDNs.

## Local Development

No build system is required.

1. Clone the repository.
2. Open `index.html` in a browser or serve the project with a local static server.
3. Navigate through the pages using the site navigation.

## Deployment

The website is deployed as a static site using GitHub Pages.

## Project Status

This is a frontend e-commerce project/demo. It does not currently provide a complete backend, authentication, payment processing, or real order-management system.
